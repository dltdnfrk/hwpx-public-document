# 문서작성기 수동 시운전 지시서

> 대상: HWPX Public Document Studio / 문서작성기  
> 시운전 문서: 「과수화상병 예방체계 고도화를 위한 과원 위생관리 정책 제언」  
> 목적: 실제 사용자가 문서 작성·저장·복구·조판·내보내기를 직접 수행하고 결함을 기록한다.

## 1. 시운전 원칙

- 이 지시서는 **사용자 직접 QA용**이다. VoiceOver는 사용하지 않는다.
- 기존 파일과 기존 앱을 덮어쓰지 않는다. 새로운 작업 폴더와 증거 폴더만 사용한다.
- HWPX/HWP의 의미 손실이 감지되면 차단되는 것이 정상이다. 차단을 우회하거나 허용 형식을 임의로 바꾸지 않는다.
- 내보내기 실패 시 같은 경로에 재시도하지 말고 새 폴더를 만든다.
- 커밋·푸시는 하지 않는다.

## 3. 시운전용 앱 준비

저장소 루트에서 실행한다.

```sh
cd /Users/hyunjun/Documents/MUNI/hwpx-public-document

trial_id="$(date +%Y%m%d-%H%M%S)"
trial_root="$PWD/.omo/evidence/manual-user/$trial_id"
mkdir -p "$trial_root"

swift build --product PublicDocumentApp
PUBLIC_DOCUMENT_PACKAGE_PARENT="$trial_root" \
  scripts/package-macos-app.sh "$trial_root/PublicDocument.app"

open "$trial_root/PublicDocument.app"
```

확인할 사항:

- 앱 창 제목이 **문서작성기**인지 확인한다.
- 상단에 **새 문서, 저장, 다시 열기, 복구, 프로젝트 검사, 내보내기**가 보이는지 확인한다.
- 리본 탭에 **홈, 삽입, 표, 레이아웃, 검토, 보기**가 보이는지 확인한다.
- 화면 하단에 페이지 수, 언어, 보기 배율 상태가 보이는지 확인한다.
- 앱이 뜨지 않거나 영문 오류만 표시되면 즉시 FAIL로 기록한다.

## 4. 기본 작성 시나리오

### 4.1 새 문서 생성

1. **새 문서**를 누른다.
2. 필수 절 채우기 창이 열리면 이번 시험에서는 **건너뛰기** 또는 닫기를 누른다.
3. 문서 제목 입력란에 다음 제목을 넣는다.

```text
과수화상병 예방체계 고도화를 위한 과원 위생관리 정책 제언
```

4. 본문 편집 영역을 선택한다.
5. **부록 A**에서 첫 제목 줄을 제외한 나머지 원문 전체를 복사해 붙여 넣는다.
6. 붙여 넣은 직후 원문의 Ⅰ~Ⅹ 장이 순서대로 존재하는지 확인한다.

기대 결과:

- 제목이 별도의 제목 요소로 유지된다.
- 본문에 Ⅰ부터 Ⅹ까지 빠짐없이 들어간다.
- `○`, `-`, 괄호, 가운데점, 법령명 괄호가 깨지지 않는다.
- 두 칸 공백, 줄바꿈, 탭 등 사용자가 입력한 공백을 저장·DOCX·Markdown에서 임의로 한 칸으로 줄이지 않는다.

### 4.2 문서 구조와 조판

1. **문서 구조** 패널에서 각 장을 차례로 누른다.
2. 구조 항목을 누를 때 실제 본문 편집 위치로 포커스가 이동하는지 확인한다.
3. 제목, `Ⅰ. ~ Ⅹ.`, `○`, `-`의 계층과 내어쓰기를 확인한다.
4. **보기** 탭에서 쪽 미리보기를 켠다.
5. 제목이나 장 제목이 페이지 맨 아래에 홀로 남지 않는지 확인한다.
6. 긴 항목과 다음 항목이 겹치거나 잘리지 않는지 확인한다.

불합격 예:

- 장 번호가 본문과 분리되거나 순서가 바뀜
- 내어쓰기가 단계마다 같아 계층이 보이지 않음
- 페이지 경계에서 글자가 잘리거나 표가 중복됨
- 미리보기와 편집 화면의 표 테두리·배경색이 서로 다름

## 5. 한글 문서 편의기능 시나리오

본문 마지막에 임시 시험 문단을 만든 뒤 다음 기능을 순서대로 실행한다.

1. **날짜 넣기**: 날짜가 기존 글자와 붙지 않고 공백을 두고 삽입되는지 확인한다.
2. **기간 넣기**: 시작일과 종료일 순서가 잘못되면 적용되지 않는지 확인한다.
3. **금액→한글**: `12,500,000`을 입력해 아래 결과가 만들어지는지 확인한다.

```text
12,500,000원(금일천이백오십만원정)
```

4. 잘못된 금액 `1,2`, `12,34`, `1,,000`은 자동 보정하지 않고 거부하는지 확인한다.
5. **붙임**을 넣어 `붙임 1. 성과지표 1부.`처럼 삽입되는지 확인한다.
6. **끝**을 넣어 앞 문장과 붙지 않고 `끝.`으로 삽입되는지 확인한다.
7. 같은 문장에 낫표 기능을 두 번 눌러 `「「문장」」`처럼 중첩되지 않는지 확인한다.
8. 실행 취소 후 다시 실행하여 동일한 문서 상태로 돌아오는지 확인한다.

기대 예시:

```text
기본 2026. 8. 31. 12,500,000원(금일천이백오십만원정) 붙임 1. 성과지표 1부. 끝.
```

날짜는 시험일에 맞게 달라질 수 있으나 각 토큰 사이의 공백은 유지돼야 한다.

## 6. 표 시나리오

원문과 별도로 시험용 표를 만든다.

1. **표** 탭에서 2열 2행 표를 추가한다.
2. 첫 행에 `구분`, `값`, 둘째 행에 `교육`, `95`를 입력한다.
3. 행 추가를 눌러 셋째 행이 정확히 한 번 추가되는지 확인한다.
4. 표 테두리가 문서 표준색 `#7f8986` 계열로 보이는지 확인한다.
5. 셀 배경색을 적용하고 다른 셀 내용이 사라지지 않는지 확인한다.
6. 저장 후 다시 열어 행 수, 셀 순서, 값이 유지되는지 확인한다.

불합격 예:

- 행 추가 시 기존 행이 복제·삭제됨
- 표 내용이 한 줄 텍스트로 바뀜
- 저장 후 셀 순서가 바뀜
- 미리보기와 편집 화면의 표 규칙이 다름

## 7. 저장·다시 열기·복구 시나리오

1. **저장**을 누른다.
2. 제목, Ⅰ~Ⅹ 원문, 임시 시험 문단, 표가 모두 남아 있는지 확인한다.
3. 문장 하나를 수정한 뒤 **실행 취소**와 **다시 실행**을 각각 한 번 수행한다.
4. **다시 열기**를 눌러 마지막 저장 상태가 복원되는지 확인한다.
5. 앱을 정상 종료하고 같은 앱을 다시 실행한다.
6. 복구 자료가 있을 때만 **복구**를 눌러 복구 상태를 확인한다.
7. **프로젝트 검사**에서 문서·저장본·요소 수·리비전 수가 비어 있지 않은지 확인한다.

즉시 FAIL 조건:

- 저장 후 원문 일부가 없어짐
- 다시 열기 후 표나 장 순서가 달라짐
- 실행 취소가 다른 문서의 상태를 불러옴
- 프로젝트 검사에 내부 파일 경로나 비밀값이 노출됨

## 8. 내보내기 시나리오

### 8.1 원문만 있는 문서

1. 표를 넣기 전 상태 또는 표를 삭제한 복사본을 준비한다.
2. **내보내기**에서 HWPX, HWP, DOCX, Markdown을 선택한다.
3. 필요한 시각 변환 동의가 있으면 내용을 읽고 이번 내보내기에만 동의한다.
4. 결과 창에서 게시·차단·실패 건수를 기록한다.
5. 생성 파일을 각각 열어 제목, Ⅰ~Ⅹ 순서, 문장, 글머리표, 줄바꿈을 확인한다.

### 8.2 표가 있는 문서

1. 표를 포함한 상태에서 같은 네 형식을 선택한다.
2. 의미 손실 형식은 **차단**되어야 한다.
3. HWPX/HWP가 표 의미 손실로 차단되면 정상 정책 동작으로 기록한다.
4. DOCX와 Markdown이 게시되면 표 행·열과 텍스트를 확인한다.
5. 선택하지 않은 형식의 실패가 결과 창에 나타나면 FAIL로 기록한다.

### 8.3 파일별 확인표

| 형식 | 확인 항목 | 판정 |
| --- | --- | --- |
| HWPX | ZIP 서명, 제목·본문 순서, Ⅰ~Ⅹ, 차단 정책 |  |
| HWP | 파일 열림, 본문 순서, 변환 오류의 한국어 안내 |  |
| DOCX | 제목 스타일, 공백·줄바꿈, 글머리표, 표 구조 |  |
| Markdown | 원문 공백·줄바꿈, 장 순서, 특수문자 |  |

안전 확인:

- 기존 대상 파일을 덮어쓰지 않아야 한다.
- 모든 형식이 차단되면 `document.typ`, `document.pdf` 등 부수 파일도 새로 쓰거나 기존 파일을 변경하면 안 된다.
- 내보내기 실패를 성공으로 표시하면 안 된다.
- 실행 실패와 의미 손실 차단을 다른 상태로 표시해야 한다.

## 9. 잘못된 입력·보안 시나리오

1. 비어 있는 문서에서 내보내기를 시도한다.
2. 잘못된 프로젝트 파일을 열어 본다.
3. 기대 안내:

```text
프로젝트 작업을 완료하지 못했습니다. 원본은 변경하지 않았습니다. 프로젝트를 다시 열거나 복구를 선택하세요.
```

4. 오류 후 기존 문서와 기존 대상 파일이 변경되지 않았는지 확인한다.
5. AI 제공자를 저장하지 않은 상태에서 **AI 제안**을 연다.
6. 제공자·엔드포인트·모델·작업·전송 범위 동의 전에는 요청이 전송되지 않는지 확인한다.
7. 화면과 프로젝트 검사에 API 키·토큰·키체인 비밀값이 나타나지 않는지 확인한다.

## 10. 최종 합격 기준

다음을 모두 만족하면 PASS다.

- 원문 Ⅰ~Ⅹ이 저장·다시 열기·내보내기 후에도 빠짐없다.
- 제목·장·항목·세부항목의 계층과 내어쓰기가 육안으로 구분된다.
- 표의 행·열·내용·테두리가 편집, 저장, DOCX에서 일치한다.
- 사용자가 입력한 공백과 줄바꿈이 DOCX와 Markdown에서 보존된다.
- 의미 손실 형식은 게시되지 않고 명확히 차단된다.
- 기존 파일을 덮어쓰지 않는다.
- 오류 안내가 한국어이며 다음 조치가 명확하다.
- 저장, 다시 열기, 복구, 실행 취소, 다시 실행이 다른 문서 상태를 섞지 않는다.
- AI 동의 전 전송이 없고 비밀값이 노출되지 않는다.
- 앱 종료 후 테스트용 프로세스가 남지 않는다.

하나라도 충족하지 않으면 FAIL 또는 환경 BLOCKED로 기록하고 실패 직후 추가 편집을 멈춘 뒤 증거를 보존한다.

## 12. 종료 및 정리

1. 문서작성기를 정상 종료한다.
2. 다음 명령으로 테스트 프로세스가 남지 않았는지 확인한다.

```sh
pgrep -alf PublicDocumentApp || true
```

3. 시험 증거 폴더는 그대로 보존한다.
4. FAIL이면 출력 파일을 다시 저장하거나 수정하지 않는다.
5. 시운전 결과와 결함 기록을 함께 전달한다.

## 부록 A. 시운전용 원문

아래 블록은 사용자가 이전에 제공한 원문을 그대로 복원한 것이다. 제목 입력란에는 첫 줄의 바깥 낫표를 제외한 제목을 넣고, 본문에는 둘째 줄부터 붙여 넣는다.

```text
「과수화상병 예방체계 고도화를 위한 과원 위생관리 정책 제언」
과수화상병 방역의 실효성을 높이기 위해 예찰·신고·진단 및 발생 후 방제와 함께, 농작업 전후 작업도구·복장·신발의 위생관리, 이동 작업팀 교육 및 작업이력 관리를 하나의 예방체계로 연계할 것을 제언함.

Ⅰ. 제언 요지
○ 과수화상병은 발생 이후 치료가 어렵고 방제 과정에서 농가에 큰 경제적·심리적 부담을 초래하므로, 발생 후 대응뿐 아니라 병원체의 과원 유입과 농가 간 이동 위험을 줄이는 예방적 관리가 중요함.
○ 현행 「식물방역법」과 관련 하위규정은 농작업 전후 작업자·복장·신발·작업도구의 소독, 예방교육, 예찰 및 신고 등을 규정하고 있음. 다만 실제 농작업 현장에서는 교육의 전달력, 위생조치의 이행 여부 확인, 이동 작업팀의 작업이력 관리 및 반복적인 피드백 체계가 충분히 연결되지 못하고 있음.
○ 농림축산검역본부의 과수화상병 역학조사에서는 병원균에 오염된 작업도구 등이 주요 확산 요인으로 제시되어 왔음. 특히 전정·적화·적과 작업을 위해 여러 과원과 지역을 이동하는 작업팀은 작업도구·복장·신발을 통한 교차오염 가능성을 고려하여 위험기반 관리가 필요한 대상임.
○ 이에 따라 다음 세 가지 정책 방향을 제언함.
1. 작업 전후 및 과원 간 이동 시 적용할 수 있는 과원 위생관리 표준지침 마련
2. 이동 작업팀을 대상으로 한 다국어 예방교육·최소 작업이력·위생조치 확인체계 도입
3. 현장 위생점검 보조기술의 독립적 성능검증 및 공공 활용 평가체계 구축
○ 초기에는 고위험 지역과 다지역 이동 작업팀을 대상으로 제한적으로 실증하고, 교육·위생행동·작업기록·독립 오염지표·비용·수용성을 평가한 후 제도화 범위를 단계적으로 결정하는 것이 적절함.
Ⅱ. 정책 제언의 배경
1. 발생 후 대응만으로는 농가의 불안을 해소하기 어려움
○ 현행 과수화상병 방역은 예찰, 의심 증상 신고, 공식 진단 및 발생농가 방제조치를 중심으로 운영되고 있음.
○ 이러한 체계는 발생을 확인하고 확산에 대응하기 위한 필수 절차이나, 농가 입장에서는 외부 작업인력과 장비가 과원에 들어오기 전에 위생조치가 적절하게 이루어졌는지 확인하기 어려움.
○ 특히 전정·적화·적과·수확 시기에는 외부 인력과 작업도구의 이동이 집중되므로, 과원에 들어오기 전과 작업 종료 후의 위생관리를 별도의 예방 단계로 구체화할 필요가 있음.
2. 작업도구는 조건에 따라 기계적 전파 관리대상이 될 수 있음
○ 감염조직이나 세균성 삼출물에 접촉한 전정가위·톱 등의 작업도구는 오염량, 수분, 유기물, 환경조건 및 다음 작업까지의 시간 등에 따라 병원체의 기계적 전파경로가 될 수 있음.
○ 이에 따라 현행 예방수칙에서도 작업 전후 작업도구와 복장·신발 등의 소독을 요구하고 있으며, 작업도구 위생관리는 기존 방역정책과 분리된 새로운 개념이 아니라 현행 예방조치를 현장에서 구체화하는 과정으로 볼 수 있음.
○ 다만 특정 연도 역학조사에서 제시된 것으로 알려진 ‘외부작업자 작업도구 46%’ 수치는 현재 공개된 원문만으로 조사대상, 분자·분모, 경로 분류 및 판정 범위를 확인하기 어려움. 원문 표와 통계 범위가 확인되기 전에는 전체 전파경로에 대한 일반적 비율로 사용하지 않는 것이 적절함.
3. 문제는 규정의 부재보다 현장 이행체계의 공백임
○ 예방교육과 작업도구 소독 의무는 이미 마련되어 있으나, 농작업 현장에서는 다음과 같은 실행상 한계가 존재함.
- 작업자가 실제 사용하는 언어와 문해 수준을 반영한 교육자료 부족
- 교육 이수 여부보다 실제 작업 수행능력을 확인하는 절차 부족
- 작업 전후 도구의 세척·소독 여부를 확인할 공통 점검기준 부족
- 여러 농가와 시군을 이동하는 작업팀의 최소 작업이력 단절
- 위생조치 미흡 시 즉시 재조치하고 기록하는 피드백 체계 부족
- 농가·작업팀·농협·농업기술센터가 함께 사용할 수 있는 표준양식 부족
○ 따라서 새로운 규제를 일률적으로 추가하기보다, 현재 존재하는 예방수칙이 현장에서 실제 행동으로 이어지도록 교육·점검·재조치·기록을 하나의 관리체계로 연결하는 것이 우선되어야 함.
Ⅲ. 정책 추진의 기본 방향
1. 공식 진단체계와 현장 위생관리체계의 분리
○ 과수화상병 의심 증상에 대한 신고와 진단은 기존 공식 절차에 따라 수행되어야 하며, 민간 위생점검 보조기술의 결과가 신고 여부나 식물체 제거 여부를 결정해서는 안 됨.
○ 공식 질병관리 절차는 다음과 같이 유지함.
의심 증상 발견 → 제품 반응과 관계없이 관할기관 신고 → 식물방역관 조사 → 공식 정밀진단 → 방제조치

○ 별도의 작업도구 위생관리 절차는 다음과 같이 운영할 수 있음.
작업 전 교육·점검 → 승인된 절차에 따른 세척·소독 → 작업 투입 → 작업 후 점검·기록 → 필요 시 재세척·도구 분리 및 후속 확인

○ 이를 통해 위생관리 보조기술이 공식 진단을 대체하거나 방해하지 않으면서, 기존 예방수칙의 현장 이행을 지원하도록 역할을 명확히 구분해야 함.
2. 규제보다 실행지원과 자율참여를 우선
○ 전국 농작업업체 또는 이동 작업팀을 즉시 의무등록 대상으로 지정하기보다, 다지역 이동빈도가 높거나 발생지역·인접지역에서 활동하는 작업팀을 중심으로 자율인증형 관리모델을 먼저 검증할 필요가 있음.
○ 초기 정책은 처벌보다 다음과 같은 지원과 유인을 중심으로 설계하는 것이 바람직함.
- 무료 또는 저비용 다국어 예방교육
- 표준 소독물품과 위생관리 키트 제공
- 교육·위생관리 이수 작업팀 인증
- 농협·작목반과 인증 작업팀의 연결 지원
- 간편한 작업기록 양식 제공
- 우수 참여팀에 대한 교육·사업 참여 인센티브
3. 제품보다 관리시스템 중심으로 평가
○ 식품·의료 분야에서는 시각적 위생점검 기술이 교육, 표준절차, 점검, 즉시 피드백, 재조치 및 반복관리와 결합될 때 청소·위생 과정지표를 개선할 가능성이 보고되어 있음.
○ 따라서 현장 위생점검 보조기술도 제품만 배포하는 방식이 아니라 다음과 같은 관리 패키지로 실증해야 함.
다국어 교육 + 표준 세척·소독 절차 + 현장 점검 + 재조치 기준 + 작업기록 + 관리자 피드백

○ 제품의 형광 반응 건수만을 성과로 평가해서는 안 되며, 실제 위생행동의 변화와 독립적인 오염지표, 작업부담 및 비용을 함께 확인해야 함.
Ⅳ. 주요 정책 제언
제언 1. 과원 위생관리 표준지침 마련
○ 농작업 전후 및 과원 간 이동 시 적용할 수 있는 작업도구·복장·신발 위생관리 표준절차를 마련할 것을 제언함.
○ 표준지침에는 다음 사항을 포함할 필요가 있음.
- 작업 시작 전 도구 상태와 오염 여부 점검
- 승인된 세척·소독제의 사용방법, 농도 및 접촉시간
- 전정가위·톱·장갑·장화 등 품목별 위생관리 방법
- 과원 간 이동 시 재세척·재소독 기준
- 작업 종료 후 도구의 세척·건조·보관 절차
- 세척·소독이 어렵거나 오염이 의심되는 도구의 분리 기준
- 의심 증상 발견 시 공식 신고절차
- 농가와 작업팀이 함께 확인할 수 있는 작업 전후 점검표
○ 소독 효과는 오염량, 유기물, 표면상태, 제품 농도, 적용방식 및 접촉시간 등에 따라 달라질 수 있으므로, 단순히 소독제 보유 여부를 확인하는 데 그치지 않고 적정 절차의 이행 여부를 관리해야 함.
제언 2. 이동 작업팀 대상 다국어 교육·이력관리 도입
○ 여러 농가와 지역을 이동하는 작업팀을 대상으로 다국어 예방교육, 최소 작업이력 및 위생조치 확인을 연계한 자율인증형 관리체계를 우선 도입할 것을 제언함.
○ 관리대상은 국적이 아니라 다음의 위험기준으로 선정해야 함.
- 일정 기간 내 방문한 과원 또는 시군의 수
- 전정·적화·적과 등 식물체와 직접 접촉하는 작업유형
- 화상병 발생지역 또는 인접지역 방문 여부
- 도구 공동사용 여부
- 작업팀의 상시·계절 이동범위
○ 교육은 한국어 자료를 단순 번역하는 방식에서 벗어나 다음 요소를 포함해야 함.
- 작업자가 실제 사용하는 언어별 짧은 교육자료
- 사진·그림·순서도 중심의 저문해 자료
- 실제 작업도구를 활용한 현장시범
- 작업자가 직접 절차를 다시 수행하는 이해 확인 방식
- 작업 전 브리핑과 작업 후 피드백
- 현장반장 또는 동료교육자를 통한 반복 보강
○ 작업이력은 방역 목적에 필요한 최소정보만 수집함.
- 작업팀 또는 업체 식별정보
- 예방교육 이수 여부
- 작업일자와 시·군 단위 작업지역
- 작업유형
- 작업 전후 도구 위생조치 여부
- 이상상황과 재조치 내용
- 농가 또는 현장관리자 확인
○ 상시 위치추적, 과도한 개인식별정보, 필요 이상의 작업자 명단 및 무기한 중앙보관은 지양해야 함. 평시에는 농가·작업팀이 기록을 보관하고, 적법한 역학조사나 행정절차가 필요한 경우 제출하는 분산형 방식도 검토할 수 있음.
제언 3. 현장 위생점검 보조기술의 검증·활용체계 구축
○ 농작업 도구와 표면의 위생관리를 지원하는 민간 기술에 대해 분석성능, 현장 재현성, 행동개선 효과 및 법적 적용범위를 독립적으로 평가할 수 있는 체계를 마련할 것을 제언함.
○ 미리바와 같은 형광 기반 보조기술은 다음과 같이 제한된 역할로 우선 검증하는 것이 적절함.
정해진 사용·조명 조건에서 농작업 도구나 표면에 나타나는 형광 반응을 시각적으로 확인하여, 세척 또는 후속 확인이 필요한 후보 지점을 찾도록 돕는 현장 위생관리 보조수단

○ 현 단계에서는 다음 한계를 명확히 고지해야 함.
- 형광 반응만으로 특정 병원체의 존재를 판정하지 않음
- 생균 여부, 병원성 또는 식물 감염 여부를 판정하지 않음
- 무반응도 병원체·미생물·잔류물의 부재나 위생 안전을 보증하지 않음
- 과수화상병 의심 증상은 제품 반응과 관계없이 관계기관에 신고해야 함
- 제품 결과로 식물체 제거 또는 공식 방제조치를 결정하지 않음
○ 민간 기술의 평가는 다음 세 영역으로 분리해야 함.
가. 분석성능 평가
- 용매·용기·조명·표면에서 발생하는 배경 형광
- 표적과 비표적 미생물의 반응 차이
- 토양·수액·농약·소독제·먼지 등 현장 간섭
- 농도·온도·습도·건조시간에 따른 변화
- 제품 로트·작업자·일자별 반복성
- 판독자 간 결과 일치도
- 실제 농작업 표면에서의 재현성
나. 행동·운영효과 평가
- 점검 결과를 올바르게 해석하는 비율
- 이상 확인 후 적정한 재조치 비율
- 결과 확인부터 재조치까지 걸린 시간
- 도구 위생절차 준수율 변화
- 작업기록 작성과 지속사용 여부
다. 제도·법적 적용범위 평가
- 공식 진단절차와의 관계
- 제품의 법적 분류
- 표시·광고에 허용되는 효능 범위
- 공공사업 또는 현장교육에서의 활용조건
○ 분석성능이 확인되지 않은 상태에서 특정 병원체의 ‘양성·음성’, ‘특이 검출’, ‘확진’, ‘30초 진단’, ‘예방·차단 효과’로 확대 표현하지 않아야 함.
제언 4. 단계적 실증 후 정책사업과 연계
○ 과원 위생관리 정책은 전국 의무화보다 고위험 지역과 다지역 이동 작업팀을 대상으로 한 단계적 실증부터 추진할 것을 제언함.
○ 시범운영은 다음 두 집단을 비교하는 방식으로 설계할 수 있음.
- 통상관리군: 기존 예방교육·소독지침 적용
- 위생관리 강화군: 다국어 교육, 표준절차, 최소 작업기록, 현장 점검, 재조치 및 관리자 피드백 적용
○ 제품을 제공하는 기관과 효과를 평가하는 기관을 분리하고, 가능한 경우 결과평가자가 참여집단 배정을 모르게 하여 평가의 객관성을 높여야 함.

Ⅴ. 단계별 추진방안
1단계: 정책·실증 설계
○ 관계기관 협의를 통해 정책 목적, 참여대상, 적용지역과 역할을 확정함.

○ 이동 작업팀 최소 작업기록 항목, 보관기간, 열람범위 및 폐기절차를 정함.
```
