## Local structural and semantic gate

The verifier does not trust the receipt's top-level verdict booleans. On every verification it:

1. Reloads the frozen corpus, capability matrix, and fixture projects and checks their exact hashes.
2. Recomputes all eight fixture-by-format dispositions from the current loss policy.
3. Requires each semantic-loss disposition to match the matrix exactly and to publish no artifact.
4. Re-reads each artifact-validated file from the receipt root, checks its byte count and SHA-256, and reopens it with the current artifact validator.
5. Compares the fresh artifact-derived validator receipt, including ordered element IDs, kinds, order, and text hashes, with the stored validation snapshot.

A stale artifact, altered validation snapshot, missing disposition, extra artifact, or capability-gap disagreement is rejected instead of being converted into `BLOCKED`.
